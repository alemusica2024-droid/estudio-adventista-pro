⚙️ Uso, durabilidad y fuentes

La aplicación centraliza recursos; no suplanta sus licencias

Versiones bíblicas: abre la RVR1960, Dios Habla Hoy, TLA y otras traducciones desde Bible Gateway. El texto de esas ediciones permanece en el sitio del editor/proveedor, no se descarga o re-publica aquí.

Thompson: su sistema de notas original es un recurso editorial protegido; para usarlo mediante Logos hay que tener la licencia. La aplicación contiene además cadenas temáticas originales, sin restricciones de uso propias de Thompson.

White y Bullón: enlaces a sus bibliotecas o publicaciones. Ninguna nota propia es una cita textual atribuida a ellos.

Qué sigue funcionando si se cae Internet

El panel, tus notas, el taller de sermones, los apuntes, las cadenas temáticas propias y la clase de ejemplo pueden funcionar después de cargar la aplicación desde un sitio HTTPS compatible con PWA. Las Biblias externas, Thompson y las lecciones vigentes requieren acceso al proveedor.

Los datos escritos se almacenan en este navegador y no se sincronizan automáticamente con otros celulares. Exporta respaldos regularmente. El navegador, WebView o el proveedor de alojamiento pueden borrar datos o cambiar su comportamiento.

Propuesta de durabilidad

Publica esta web en GitHub Pages con HTTPS, conserva una copia del ZIP y revisa periódicamente los enlaces externos. Si AppCreator24 deja de funcionar, el mismo sitio puede abrirse desde Chrome. Para sincronizar notas entre equipos hará falta agregar posteriormente un servidor y autenticación.
